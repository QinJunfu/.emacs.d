#+TITLE: Emacs 快捷键备忘录
#+STARTUP: overview

* 如何读这份表

- ~C-~：按住 ~Ctrl~；~M-~：通常是按住 ~Alt~；~S-~：按住 ~Shift~。
- 连续写出的键要依次按。例如 ~C-x C-f~ 是先按 ~Ctrl+x~，松开后再按 ~Ctrl+f~。
- ~RET~ 是回车，~TAB~ 是 Tab，~SPC~ 是空格，~DEL~ 是 Backspace，~ESC~ 是 Escape。
- 带“前缀”的快捷键要再按一个键。例如 ~C-x~、~C-c~、~C-h~；等候片刻可由 which-key 显示后续选择。
- Emacs 的键位会随当前 major mode、minor mode 和插件而变化。本文件列出新手最常用的标准键位和本配置已确认的自定义键位；要查当前实际键位，请看最后的“发现与帮助”。
  
* 必记的十个键

| 快捷键    | 作用                        |
|-----------+-----------------------------|
| ~C-x C-f~ | 打开文件。                  |
| ~C-x C-s~ | 保存文件。                  |
| ~C-x b~   | 切换已打开的文件。          |
| ~C-g~     | 取消当前操作。              |
| ~C-s~     | 搜索。                      |
| ~M-x~     | 按名称执行任意 Emacs 命令。 |
| ~C-SPC~   | 开始或结束选择文本。        |
| ~C-w~     | 剪切选中内容。              |
| ~M-w~     | 复制选中内容。              |
| ~C-y~     | 粘贴。                      |

* 文件、buffer 与退出

buffer 是 Emacs 正在编辑或显示的一份内容，通常对应一个文件，也可能是搜索结果、终端或帮助页面。

| 快捷键        | 作用                                                   |
|---------------+--------------------------------------------------------|
| ~C-x C-f~     | 打开文件；输入不存在的路径可新建文件。                 |
| ~C-x C-s~     | 保存当前文件。                                         |
| ~C-x C-w~     | 另存为。                                               |
| ~C-x i~       | 将另一个文件的内容插入光标处。                         |
| ~C-x C-r~     | 以只读模式打开文件。                                   |
| ~C-x C-q~     | 切换当前 buffer 的只读模式；再次按恢复可编辑。         |
| ~C-x k~       | 关闭当前 buffer；文件不会自动删除。                    |
| ~C-x b~       | 切换 buffer；本配置使用 Ivy 的搜索式选择界面。         |
| ~C-x C-b~     | 显示 buffer 列表。                                     |
| ~C-x <left>~  | 切换到上一个 buffer。                                  |
| ~C-x <right>~ | 切换到下一个 buffer。                                  |
| ~C-x d~       | 打开 Dired 文件管理器。                                |
| ~C-x C-c~     | 退出 Emacs；有未保存内容时会询问。                     |

* 光标移动与滚动

| 快捷键            | 作用                                       |
|-------------------+--------------------------------------------|
| ~C-f~ / ~C-b~     | 向前 / 向后一个字符。                      |
| ~C-n~ / ~C-p~     | 下一行 / 上一行。                          |
| ~C-a~             | 到代码首字符；再次按到行首。               |
| ~C-e~             | 到代码末字符；再次按到行尾。               |
| ~M-f~ / ~M-b~     | 向前 / 向后一个单词。                      |
| ~M-a~ / ~M-e~     | 到句首 / 句尾。                            |
| ~C-M-f~ / ~C-M-b~ | 向前 / 向后一个表达式。                    |
| ~M-<~ / ~M->~     | 到文件开头 / 文件末尾。                    |
| ~C-v~ / ~M-v~     | 向下 / 向上翻页。                          |
| ~C-l~             | 将当前行重新置于窗口中央。                 |
| ~M-g g~           | 跳转到指定行。                             |
| ~C-j~             | Avy 两字符跳转；输入两字符后按提示键定位。 |

* 选择、编辑与撤销

| 快捷键           | 作用                                 |
|------------------+--------------------------------------|
| ~C-SPC~          | 设置标记；移动光标以选择区域。       |
| ~C-x h~          | 选择整个 buffer。                    |
| ~C-w~            | 剪切选中区域，或从光标剪切到标记处。 |
| ~M-w~            | 复制选中区域。                       |
| ~C-y~            | 粘贴最近剪切或复制的内容。           |
| ~M-y~            | 刚粘贴后循环选择更早的剪切内容。     |
| ~C-d~ / ~DEL~    | 删除光标后 / 前一个字符。            |
| ~M-d~ / ~M-DEL~  | 删除后 / 前一个单词。                |
| ~C-k~            | 剪切到行尾；在空行再按会删除换行。   |
| ~C-x DEL~        | 剪切到行首。                         |
| ~C-t~            | 交换相邻字符。                       |
| ~M-t~            | 交换相邻单词。                       |
| ~C-x C-t~        | 交换当前行和上一行。                 |
| ~C-/~ 或 ~C-x u~ | 撤销。                               |
| ~C-x r t~        | 矩形区域填入指定文本。               |
| ~C-x r k~        | 剪切矩形区域。                       |
| ~C-x r y~        | 粘贴矩形区域。                       |

* 搜索、替换与跳转位置

| 快捷键      | 作用                                                              |
|-------------+-------------------------------------------------------------------|
| ~C-s~       | 向前搜索；本配置使用 Swiper，可输入内容实时筛选。                 |
| ~C-r~       | 向后搜索。                                                        |
| ~C-s C-w~   | 搜索光标处的单词。                                                |
| ~M-%~       | 交互式替换。每处可选 ~y~ 替换、~n~ 跳过、~!~ 全部替换、~q~ 退出。 |
| ~C-M-%~     | 使用正则表达式的交互式替换。                                      |
| ~M-g g~     | 跳转到指定行。                                                    |
| ~C-x C-SPC~ | 打开标记环选择器；本配置使用 Counsel 界面。                       |
| ~C-u C-SPC~ | 跳转到全局标记环中较早的位置。                                    |
| ~C-x r m~   | 设置书签。                                                        |
| ~C-x r b~   | 跳转到书签。                                                      |
| ~C-x r l~   | 列出书签。                                                        |

* 窗口、frame 与显示

窗口是一个 buffer 的显示区域；frame 是一个 Emacs 图形窗口。

| 快捷键        | 作用                                                        |
|---------------+-------------------------------------------------------------|
| ~C-x o~       | 在窗口间切换；本配置启用 Ace Window，按提示键直选窗口。     |
| ~C-x 0~       | 关闭当前窗口。                                              |
| ~C-x 1~       | 只保留当前窗口。                                            |
| ~C-x 2~       | 上下分割当前窗口。                                          |
| ~C-x 3~       | 左右分割当前窗口。                                          |
| ~C-x 4 f~     | 在另一个窗口打开文件。                                      |
| ~C-x 5 2~     | 新建 frame。                                                |
| ~C-x 5 0~     | 关闭当前 frame。                                            |
| ~C-x +~       | 增大当前窗口高度。                                          |
| ~C-x -~       | 减小当前窗口高度。                                          |
| ~C-x ^~       | 增大当前窗口宽度。                                          |
| ~C-x {~ / ~C-x }~ | 减小 / 增大当前窗口宽度。                                |
| ~C-x <~ / ~C-x >~ | 向左 / 向右滚动当前窗口内容。                            |
| ~C-x 5 1~     | 只保留当前 frame。                                          |

* 帮助、命令与发现键位

不必死记所有快捷键。任何不确定的操作都先从这里查。

| 快捷键 / 命令 | 作用                                                        |
|---------------+-------------------------------------------------------------|
| ~C-g~         | 取消当前操作；卡在输入状态时先按它。                        |
| ~M-x~         | 搜索并执行命令。                                            |
| ~C-h k~       | 查询某个按键实际执行的命令；随后按要查询的键。              |
| ~C-h f~       | 查询函数或命令的说明。                                      |
| ~C-h v~       | 查询变量的说明和当前值。                                    |
| ~C-h m~       | 显示当前 major mode 的帮助和键位。                          |
| ~C-h b~       | 列出当前 buffer 中所有有效键位。                            |
| ~C-h a~       | 按关键词搜索命令。                                          |
| ~C-h i~       | 打开 Emacs Info 文档。                                      |
| ~C-h t~       | 打开 Emacs 内置教程。                                       |
| ~C-h C-h~     | 显示完整帮助入口。                                          |
| ~C-h c~       | 简短说明某个按键。                                          |

* 编程、C/C++、LSP 与补全

打开 ~.c~、~.h~、~.cpp~ 等文件时，配置会自动启动 ~lsp-mode~ 和 ~clangd~，并启用 Flycheck 检查和 Company 自动补全。

| 快捷键                          | 作用                                                        |
|---------------------------------+-------------------------------------------------------------|
| ~M-.~                           | 查找光标下函数、变量或类型的定义。预览中按 ~RET~ 进入定义。 |
| ~M-,~                           | 返回上一个跳转位置。                                        |
| ~M-?~                           | 查找光标下符号的引用；本配置显示就地预览。                  |
| ~C-c l~                         | LSP 命令前缀；which-key 会显示当前可用的 LSP 命令。         |
| ~C-c l s~                       | 按名称搜索工作区中的函数、变量、类型等符号。                |
| ~M-x lsp-describe-session~      | 查看当前 buffer 的 LSP/clangd 连接状态。                    |
| ~M-x lsp-rename~                | 重命名光标处的符号，通常会修改所有引用处。                  |
| ~M-x lsp-format-buffer~         | 使用语言服务器格式化整个 buffer。                           |
| ~M-x flycheck-list-errors~      | 列出当前文件的检查错误和警告。                              |
| ~M-n~ / ~M-p~（Company 菜单中） | 选择下一项 / 上一项补全候选。                               |
| ~RET~（Company 菜单中）         | 接受当前补全候选。                                          |
| ~C-g~（Company 菜单中）         | 关闭补全菜单。                                              |

跨文件跳转不准确时，优先确认项目根目录是否有 ~compile_commands.json~，因为 clangd 需要它来获得正确的头文件路径和编译参数。

* Org mode

在 ~.org~ 文件中可使用以下常用键位。光标所在位置不同，部分命令的行为会不同。

| 快捷键                   | 作用                                             |                             |
|--------------------------+--------------------------------------------------+-----------------------------|
| ~TAB~                    | 循环折叠或展开当前标题、列表或表格。             |                             |
| ~S-TAB~                  | 循环折叠或展开整份文档。                         |                             |
| ~M-RET~                  | 新建同级标题；在列表中则新建同级列表项。         |                             |
| ~M-<left>~ / ~M-<right>~ | 将标题提升 / 降级。                              |                             |
| ~M-<up>~ / ~M-<down>~    | 上移 / 下移当前标题或列表项。                    |                             |
| ~C-c C-t~                | 切换 TODO 状态。                                 |                             |
| ~C-c C-s~                | 为标题设置计划时间。                             |                             |
| ~C-c C-d~                | 为标题设置截止时间。                             |                             |
| ~C-c C-c~                | 执行上下文命令，例如更新表格、标签或 TODO 状态。 |                             |
| ~C-c C-l~                | 插入或编辑链接。                                 |                             |
| ~C-c C-o~                | 打开光标处的链接。                               |                             |
| ~C-c a~                  | 打开 Org Agenda 菜单。                           |                             |
| ~C-c C-e~                | 打开导出菜单。                                   |                             |
| ~C-c '~                  | 编辑源代码块。                                   |                             |
| ~C-c C-,~                | 插入结构模板，例如源代码块。                     |                             |
| ~C-c                     | ~                                                | 将选中区域转换为 Org 表格。 |
| ~TAB~（表格中）          | 移到下一个单元格；在末尾单元格会创建新行。       |                             |
| ~S-TAB~（表格中）        | 移到上一个单元格。                               |                             |
| ~C-c -~（表格中）        | 在当前位置插入水平分隔线。                       |                             |

* Dired 文件管理器

先用 ~C-x d~ 打开目录，再在 Dired buffer 中使用。

| 快捷键        | 作用                                      |
|---------------+-------------------------------------------|
| ~RET~         | 打开光标处文件或进入目录。                |
| ~^~           | 返回父目录。                              |
| ~g~           | 刷新目录内容。                            |
| ~m~ / ~u~     | 标记 / 取消标记当前文件。                 |
| ~d~           | 标记文件等待删除。                        |
| ~x~           | 执行已标记的删除操作。                    |
| ~R~           | 重命名或移动文件。                        |
| ~C~           | 复制文件。                                |
| ~+~           | 新建目录。                                |
| ~Z~           | 压缩或解压文件。                          |
| ~q~           | 关闭 Dired buffer。                       |

* 终端与常见安全操作

| 快捷键 | 作用                                                     |
|--------+----------------------------------------------------------|
| ~C-g~  | 取消当前 Emacs 操作。                                    |
| ~C-x k~ | 关闭当前 buffer；不会删除磁盘文件。                     |
| ~C-x C-s~ | 保存；保存前可先看 mode line 中的文件名和只读标记。  |
| ~C-x C-q~ | 切换只读；适合临时防止误改。                          |
| ~C-x C-c~ | 退出 Emacs；未保存内容会提示处理。                    |

建议先熟悉“必记的十个键”、文件、移动、编辑、搜索和帮助；其余键位在需要时按 ~C-h k~ 或 ~C-h m~ 查询即可。
